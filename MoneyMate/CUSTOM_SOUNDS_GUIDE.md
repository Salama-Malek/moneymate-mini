# 🎵 Custom Sound Selection Guide for MoneyMate

## Overview

MoneyMate now supports custom sound selection, allowing you to choose your own audio files for different app actions and notifications. This feature gives you full control over how your app sounds and feels.

## ✨ What You Can Customize

### Sound Types Available:

1. **Notification Sound** - For payment reminders and alerts
2. **Success Sound** - For successful actions (adding transactions, etc.)
3. **Warning Sound** - For warnings and cautions
4. **Error Sound** - For errors and failures
5. **Click Sound** - For button presses and interactions
6. **Swipe Sound** - For swipe actions and gestures

## 📱 How to Set Custom Sounds

### Step 1: Access Sound Settings

1. Open MoneyMate
2. Go to **Settings** → **Notifications**
3. Find the **Custom Sounds** section
4. Tap **Configure**

### Step 2: Select a Sound Type

1. Choose which action you want to customize
2. Tap **Select Sound**
3. Your device's file picker will open

### Step 3: Choose Your Audio File

1. Navigate to your audio files
2. Select an audio file (MP3, WAV, M4A, etc.)
3. The file will be imported and assigned to that action

### Step 4: Test Your Sound

1. After selection, the sound will automatically play
2. You can tap **Test** anytime to hear it again
3. Tap **Remove** if you want to change it

## 🎯 Supported Audio Formats

### Primary Formats:

- **MP3** - Most common, widely supported
- **WAV** - High quality, uncompressed
- **M4A** - Apple's preferred format
- **AAC** - High quality, compressed

### Other Supported Formats:

- **OGG** - Open source format
- **FLAC** - Lossless compression
- **AIFF** - Apple's uncompressed format

## 🔧 Managing Your Custom Sounds

### View All Custom Sounds:

- Go to **Settings** → **Notifications** → **Custom Sounds**
- See all your selected sounds in one place

### Change a Sound:

1. Tap **Remove** on the current sound
2. Tap **Select Sound** to choose a new one
3. Your new selection will replace the old one

### Remove a Sound:

1. Tap **Remove** on any custom sound
2. Confirm the removal
3. The app will revert to default haptic feedback

### Test Sounds:

- Use the **Test** button to preview any sound
- Great for ensuring you've selected the right audio file

## 💡 Tips for Best Results

### Audio File Selection:

- **Keep files small** (under 2MB for best performance)
- **Use short sounds** (1-3 seconds for notifications)
- **Ensure good quality** (clear, not distorted)
- **Test volume levels** (not too loud or quiet)

### File Management:

- **Organize your sounds** in a dedicated folder
- **Use descriptive names** for easy identification
- **Backup important sounds** to cloud storage
- **Keep original files** in case you need to re-import

### Performance:

- **Avoid very long files** (over 10 seconds)
- **Use compressed formats** (MP3, AAC) for better performance
- **Don't use too many custom sounds** at once
- **Restart app** if sounds stop working

## 🚨 Troubleshooting

### Common Issues:

#### Sound Not Playing:

- Check if sound is enabled in settings
- Ensure device volume is not muted
- Verify the audio file is not corrupted
- Try removing and re-adding the sound

#### File Not Importing:

- Check file format compatibility
- Ensure file is not too large
- Verify file permissions
- Try a different audio file

#### Performance Issues:

- Reduce file sizes
- Use fewer custom sounds
- Clear app cache
- Restart the app

#### Permission Errors:

- Grant storage permissions when prompted
- Check device settings for app permissions
- Ensure file is accessible
